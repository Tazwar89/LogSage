Manual review of N=18 cases (seed 13 only — seed 7's per-case detail wasn't retained, see README limitations): human/judge pass-fail agreement 88.9% (16/18). Both disagreements point to the same root cause rather than two separate failure modes: the human reviewer graded diagnosis text alone, without the underlying log lines, so cases relying on inference from missing/implicit events (blk_3889689008984678294, judge dinged; blk_-4824699030744830846, judge credited) were harder to score blind than the judge, which always has direct log access. This is a caveat on the method, not necessarily evidence the judge is miscalibrated — a stricter replication would give the human reviewer the same raw log context the judge sees.
